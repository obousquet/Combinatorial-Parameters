  \subsection{Warmuth's $C_5$ class}\label{cl:warmuth_c5}
  \begin{definition}[Warmuth's $C_5$ class - {$C_5$}]
  Let the domain be the cyclic group $\mathbb{Z}/5\mathbb{Z}$.  A binary
  function belongs to $C_5$ precisely when, on some four consecutive cyclic
  positions, its values are $1,0,0,1$ in that order.  The value on the
  remaining position is unrestricted, so the class has ten functions.
  \end{definition}
