Blockwise-Addressing

Name: Blockwise-Addressing

Symbol:
\[\mathrm{bAdd}\]
Definition:

Following Example 2 of [ben1997online], fix $d\ge2$ with $d\mid 2^d$ and put $m=2^d$. The domain is $\{z,x_1,\ldots,x_m,y_1,\ldots,y_m\}$. There are $2m$ concepts $f_1,\ldots,f_m,g_1,\ldots,g_m$. The source proves $M_{sd}\le2$ and $M_{best}=\Omega(d)=\Omega(\log |\mathcal X|)$. The direct teaching argument recorded in the value entries gives $RTD=2$.
