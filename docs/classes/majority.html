Majority

Name: Majority

Symbol:
\[\text{Maj}\]
Definition:

Following [maass1992lower], for $n\geq1$ the majority class on $[n+1]$ consists of all $S\subseteq[n+1]$ such that $n+1\in S$ if and only if $|S\cap[n]|>n/2$. Thus the last coordinate is the strict-majority bit of the first $n$ coordinates.
