Paired-Code Separation Family

Name: Paired-Code Separation Family

Symbol:
\[\mathcal C^{\mathrm{pair}}_n\]
Definition:

For an integer $n\ge1$, put $N=2^n$, $m=4n+2$ and $X=[N]=\{1,\ldots,N\}$. Let $e_i\in\{0,1\}^{X}$ have its only nonzero bit at coordinate $i$. For a tuple $w=(w_1,\ldots,w_N)$ of binary words on $X$, write $w_i^\epsilon=w_i\oplus\epsilon e_i$, where $\epsilon\in\{0,1\}$ and $\oplus$ is coordinatewise addition modulo two. Call the tuple admissible if there do not exist an anchor index $a\in[N]$, an anchor bit $\sigma\in\{0,1\}$, pairwise distinct indices $i_1,\ldots,i_m\in[N]\setminus\{a\}$, bits $\epsilon_1,\ldots,\epsilon_m\in\{0,1\}$ and pairwise distinct coordinates $x_1,\ldots,x_m\in X$ such that, for every $j$, $$w_{i_j}^{\epsilon_j}(x_j)\ne w_a^\sigma(x_j),\qquad w_{i_j}^{\epsilon_j}(x_k)=w_a^\sigma(x_k)\quad(1\le kpaired-code separation family is $$\mathcal C^{\mathrm{pair}}_n=\{w_i^\epsilon:i\in[N],\ \epsilon\in\{0,1\}\}\subseteq\{0,1\}^{X}.$$ Repeated words are identified as the same concept. The ambient domain is exactly $X$.

Comments:

Admissible tuples exist for every n by the direct probabilistic proof in survey prop:paired-code-eluder. The lexicographic rule specifies a deterministic family; no efficient algorithm for finding that tuple is claimed. Projected distinguishing range is 2^n, while eluder dimension lies between n+1 and 8n+3. This supplies the range-larger direction of affine incomparability; the Triangular-Code Separation Family supplies the opposite direction. Both parameters grow, so these are not bounded-versus-unbounded witnesses.
