Singletons plus empty set

Name: Singletons plus empty set

Symbol:
\[\{\{i\}\}_{1\le i\le n}\cup\{\emptyset\}\]
Definition:

For $n\geq1$, the singleton-plus-empty class on domain $[n]$ is $\mathcal S_n^0=\{\emptyset\}\cup\{\{i\}:i\in[n]\}\subseteq2^{[n]}$.
