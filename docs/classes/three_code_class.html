Three-Code Class

Name: Three-Code Class

Symbol:
\[\mathcal C_{\triangle}\]
Definition:

On the three-point domain $\{x_0,x_1,x_2\}$, let $\mathcal C_{\triangle}=\{000,011,101\}$, where strings list the values at $x_2,x_1,x_0$ in that order.

Comments:

A finite witness class used to separate proper from improper unlabeled compression.
