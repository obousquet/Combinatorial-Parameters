Triangular-Code Separation Family

Name: Triangular-Code Separation Family

Symbol:
\[\mathcal C^{\triangle}_n\]
Definition:

For an integer $n\ge1$, put $N=2^n$, $k=6n+6$ and $X=[N]=\{1,\ldots,N\}$. Choose bits $b_{ij}\in\{0,1\}$ for $1\le ii$. Let $h_{N+1}$ be the all-zero word, and write $H_b=\{h_1,\ldots,h_N,h_{N+1}\}$. Call the bit array admissible if there is no set $S\subseteq X$ of size $k$ such that, for every $x\in S$, there are $f,g\in H_b$ satisfying $$f(x)\ne g(x),\qquad f(y)=g(y)\quad\text{for all }y\in S\setminus\{x\}.$$ Choose the lexicographically first admissible array, ordering its entries by increasing $i$ and then increasing $j$, with $0<1$. The triangular-code separation family is $\mathcal C^{\triangle}_n=H_b$ for this selected array. The ambient domain is exactly $X$.

Comments:

Admissible arrays exist for every n by the direct probabilistic proof in survey prop:triangular-code-range. The lexicographic rule defines a deterministic family, without an efficient construction claim. Eluder dimension is 2^n, while projected distinguishing range lies between n+1 and 6n+5. This separates in the opposite direction to the Paired-Code Separation Family. Both smaller parameters grow; this does not give bounded-versus-unbounded witnesses.
