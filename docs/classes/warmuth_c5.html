Warmuth's $C_5$ class

Name: Warmuth's $C_5$ class

Symbol:
\[C_5\]
Definition:

Let the domain be the cyclic group $\mathbb{Z}/5\mathbb{Z}$. A binary function belongs to $C_5$ precisely when, on some four consecutive cyclic positions, its values are $1,0,0,1$ in that order. The value on the remaining position is unrestricted, so the class has ten functions.

Comments:

This is also called Warmuth's example. It is a finite separation between unlabeled sample-compression size and VC dimension.
