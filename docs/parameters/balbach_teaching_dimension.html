Balbach Teaching Dimension

Name: Balbach Teaching Dimension

Symbol:
\[\mathrm{BTD}\]
Definition:

Let $X$ be a finite domain and $\mathcal H\subseteq\{0,1\}^X$ a nonempty finite binary class. A labeled sample $S\subseteq X\times\{0,1\}$ contains at most one label per coordinate; a concept is consistent with $S$ when it agrees with every label. For each $h\in\mathcal H$, let $b^0_{\mathcal H}(h)$ be the minimum size of a sample with which $h$ is the unique consistent concept in the class (its ordinary teaching-set size). For $k\ge0$, define $C_k(S)=\{g\in\mathcal H:g\text{ is consistent with }S,\ b^k_{\mathcal H}(g)\ge|S|\}$ and $b^{k+1}_{\mathcal H}(h)=\min\{|S|:C_k(S)=\{h\}\}$. Thus the target itself must survive the same size filter as its competitors. These nonnegative integer values are nonincreasing and eventually stabilize simultaneously. The Balbach teaching dimension is $\mathrm{BTD}(\mathcal H)=\max_{h\in\mathcal H}b^\infty_{\mathcal H}(h)$, with value zero for an empty class.

Description:

An iterated teaching parameter, monotone under subclasses and conditioning but not projections. Constant coordinates do not change it. Strict increase at equal-valued branches fails. It lies between recursive and ordinary teaching dimension and is incomparable with subset teaching dimension.

Origin References:

Introduced in [balbach2008measuring]; its basic comparisons and subclass monotonicity are proved in [zilles2011models].
