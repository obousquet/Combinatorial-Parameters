Extended Teaching Dimension

Name: Extended Teaching Dimension

Symbol:
\[\mathrm{XTD}\]
Definition:

The extended teaching dimension is $$\mathrm{XTD}(\mathcal{H}) := \max_{f\subseteq\mathcal{X}}\min\left\{|S|:S\subseteq\mathcal{X},\;\left|\{h\in\mathcal{H}:h\cap S=f\cap S\}\right|\leq 1\right\}.$$ Thus the target labeling $f$ need not belong to $\mathcal{H}$.

Description:

Equivalently, it is the largest minimum size of a specifying set for an arbitrary labeling with respect to the class. For finite binary classes it equals the star number.

Origin References:

Introduced in [hegedHus1995generalized].
