Extremal-Extension VC Dimension

Name: Extremal-Extension VC Dimension

Symbol:
\[\mathrm{VC}_{\mathrm{extr}}\]
Definition:

For a finite class $\mathcal H$, the extremal-extension VC dimension $\mathrm{VC}_{\mathrm{extr}}(\mathcal H)$ is the least $\mathrm{VC}(\mathcal E)$ among extremal (shattering-extremal) classes $\mathcal E$ on the same domain with $\mathcal H\subseteq\mathcal E$. Here extremal means that the number of shattered sets equals $|\mathcal E|$.

Description:

Measures the VC cost of embedding a class into a shattering-extremal class.

Origin References:

Defined and used in [chornomaz2025spherical].
