Largest Strongly Shattered Set

Name: Largest Strongly Shattered Set

Symbol:
\[\mathrm{ST}\]
Definition:

The Largest Strongly Shattered Set of $\mathcal{H}$ is the maximum size of a set $S$ for which $\mathcal{H}$ contains an $S$-cube: there is a set $T$ disjoint from $S$ such that $\{T\mathbin{\triangle} A:A\subseteq S\}\subseteq\mathcal{H}$.

Origin References:

Strong shattering and its extremal theory are developed in [bollobas1995defect].
