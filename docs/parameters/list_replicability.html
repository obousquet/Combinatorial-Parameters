List Replicability Number

Name: List Replicability Number

Symbol:
\[\mathrm{LR}\]
Definition:

A learner is $(\epsilon,L)$-list replicable for $\mathcal H$ if, for every $\delta>0$, some sample size makes its output lie with probability at least $1-\delta$ in a fixed list of $L$ hypotheses, all of error below $\epsilon$, for every realizable distribution. Let $\mathrm{LR}(\mathcal H,\epsilon)$ be the least such $L$ and define the list replicability number $\mathrm{LR}(\mathcal H)=\lim_{\epsilon\to0}\mathrm{LR}(\mathcal H,\epsilon)$.

Description:

A realizable PAC-learning stability parameter; its definition includes the accuracy limit $\epsilon\to0$.

Origin References:

Defined in the list-replicability framework used by [chornomaz2025spherical].
