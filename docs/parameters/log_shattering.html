Log Shattering

Name: Log Shattering

Symbol:
\[\log \mathrm{sh}\]
Definition:

Let $\operatorname{sh}(\mathcal H)=\{S\subseteq\mathcal X: \mathcal H_{|S}=2^S\}$ be the sets shattered by $\mathcal H\subseteq2^{\mathcal X}$. Its log shattering is $$\log_2|\operatorname{sh}(\mathcal H)|.$$

Category: Shattering

Symmetric: Yes

Monotonic: Yes

P-Monotonic: Yes

C-Monotonic: Yes

Strict C-Monotonic: Yes

Tight Strict C-Monotonic: Unspecified

Doubly Monotonic: Yes

Strictly Monotonic: Yes

Values:

  • $\log \mathrm{sh}(\{\emptyset, [n]\}) = \log(n+1)\;(\Omega(\log n))$
  • $\log \mathrm{sh}(\{\{i\}\}_{1\le i\le n}) = \log(n+1)\;(\Omega(\log n))$
  • $\log \mathrm{sh}(\{\{i\}\}_{1\le i\le n}\cup\{\emptyset\}) = \log(n+1)\;(\Omega(\log n))$
  • $\log \mathrm{sh}(\{[i]\}_{1\le i\le n}) = \log n\;(\Omega(\log n))$
  • $\log \mathrm{sh}(\{S:S\subset [n]\}) = n\;(\Omega(n))$
  • $\log \mathrm{sh}(C_5) = 4\;(\Omega(1))$
  • $\log \mathrm{sh}(\text{Tag}) = \log(n+\lceil\log n\rceil+1)\;(\Omega(\log n))$
  • $\log \mathrm{sh}(\text{Maj}) = \log\left(2^n+\sum_{k=0}^{\lfloor(n-1)/2\rfloor}\binom{n}{k}\right)\;(\Omega(n))$
  • $\log \mathrm{sh}(\mathcal C_{\triangle}) = 2\;(\Omega(1))$
