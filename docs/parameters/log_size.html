Log Size

Name: Log Size

Symbol:
\[\log \mathrm{H}\]
Definition:

The Log Size of a family $\mathcal{H}$ is simply the binary logarithm of its cardinality, $$ \log |\mathcal{H}|. $$

Category: Basic
