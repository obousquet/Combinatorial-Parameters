Log Size Ratio

Name: Log Size Ratio

Symbol:
\[\frac{\log (\mathrm{H}-1)}{\log (n+1)}\]
Definition:

The Log Size Ratio of a family $\mathcal{H}$ over a domain of size $n$ is $$\frac{\log(|\mathcal{H}|-1)}{\log(n+1)}.$$

Category: Basic

Symmetric: Yes

Monotonic: Yes

P-Monotonic: No

C-Monotonic: No

Strict C-Monotonic: Unspecified

Tight Strict C-Monotonic: Unspecified

Doubly Monotonic: No

Strictly Monotonic: No

Values:

  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\{S:S\subset [n]\}) = \frac{\log(2^n-1)}{\log(n+1)}\;(\Omega(\log n))$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\{\{i\}\}_{1\le i\le n}) = \frac{\log(n-1)}{\log(n+1)}\;(\Omega(1))$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\{\emptyset, [n]\}) = 0$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\{\{i\}\}_{1\le i\le n}\cup\{\emptyset\}) = \frac{\log n}{\log(n+1)}$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\{[i]\}_{1\le i\le n}) = \frac{\log(n-1)}{\log(n+1)}$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\text{Maj}) = \frac{\log(2^n-1)}{\log(n+2)}$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\text{Add}) = \frac{\log(2^{\lfloor\log n\rfloor}-1)}{\log(n+\lfloor\log n\rfloor+1)}$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\text{Tag}) = \frac{\log(n+\lceil\log n\rceil)}{\log(n+\lceil\log n\rceil+1)}$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(C_5) = \frac{\log 9}{\log 6}\;(\Omega(1))$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\mathrm{bAdd}) = \frac{\log(2^{d+1}-1)}{\log(2^{d+1}+2)}\;(\Omega(1))$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\mathcal C_{\triangle}) = \frac12$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\mathcal U_n) = \frac{\log(n-1)}{\log(2^n+1)}$ for $n\geq2$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\mathcal Q^{\cap}_n) = \frac{\log(2^n-1)}{\log(n+2)}$
  • $\frac{\log (\mathrm{H}-1)}{\log (n+1)}(\mathcal E_n) = \frac{\log(2^{n-1}-1)}{\log(n+1)}$ for $n\geq2\;(\Omega(\log n))$
