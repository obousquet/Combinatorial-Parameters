Majority Complexity

Name: Majority Complexity

Symbol:
\[\mathrm{Maj}\]
Definition:

The Majority Complexity of a finite class $\mathcal{H}$ is the number of queries used by the halving algorithm: at each stage it proposes the pointwise majority vote of the hypotheses still consistent with the answers received.

Origin References:

The query-complexity notation $\mathrm{LC}(\mathrm{Halving})$ and its lower-bound analysis appear in [maass1992lower].
