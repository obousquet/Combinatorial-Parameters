Membership Query Complexity

Name: Membership Query Complexity

Symbol:
\[\mathrm{Q}_m\]
Definition:

The Membership Query Complexity of $\mathcal{H}$ is the minimum worst-case number of membership queries needed to identify an unknown target in $\mathcal{H}$.

Origin References:

Membership queries in the exact query-learning model are introduced in [angluin1988queries].
