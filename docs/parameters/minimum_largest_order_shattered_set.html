Minimum Largest Order Shattered Set

Name: Minimum Largest Order Shattered Set

Symbol:
\[\mathrm{OSH}_{\min}\]
Definition:

Fix a linear order $\prec$ on $X$, and let $D_{\prec}(\mathcal H)$ be the class obtained by the corresponding down-shifting operation. A set $S\subseteq X$ is $\prec$-order-shattered when $D_{\prec}(\mathcal H)|_S=2^S$. The Minimum Largest Order Shattered Set is $\min_{\prec}\max\{|S|:S\text{ is }\prec\text{-order-shattered}\}$.

Origin References:

Order shattering and its downshifting formulation are part of the shattering-extremal framework; see [bollobas1995defect].
