Minimum Star Number

Name: Minimum Star Number

Symbol:
\[\mathrm{S}_{\mathrm{min}}\]
Definition:

For a finite binary class $\mathcal H$ and any (possibly unrealizable) labeling $g:\mathcal X\to\{0,1\}$, let $\mathrm S_g(\mathcal H)$ be the largest $d$ for which there are distinct points $x_1,\ldots,x_d$ and hypotheses $h_0,\ldots,h_d\in\mathcal H$ such that $h_0(x_j)=g(x_j)$ for all $j$, while $h_i(x_j)=g(x_j)$ holds exactly when $j\ne i$ for every $i\ge1$. The minimum star number is $\mathrm S_{\mathrm{min}}(\mathcal H)=\inf_g\mathrm S_g(\mathcal H)$.

Description:

Hanneke's minimum-centred-star parameter. For finite binary classes it lies between VC dimension and the ordinary star number.

Origin References:

Introduced by Hanneke in [hanneke2024star_eluder].
