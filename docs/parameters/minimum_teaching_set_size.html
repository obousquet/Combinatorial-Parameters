Minimum Teaching Set Size

Name: Minimum Teaching Set Size

Symbol:
\[\mathrm{TS}_{\min}\]
Definition:

The Minimum Teaching Set Size of $\mathcal{H}$ is $\min_{h\in\mathcal{H}}\operatorname{ts}(h,\mathcal{H})$, where $\operatorname{ts}(h,\mathcal{H})$ is the minimum size of a teaching set for $h$ in $\mathcal{H}$.

Comments:

Not c-monotonic: $\mathcal H=\{000,001,010,100,110\}$ has minimum teaching-set size $1$, while conditioning the last coordinate to $0$ gives the full two-dimensional cube, whose minimum teaching-set size is $2$.

Origin References:

This is the minimum counterpart of the classical teaching-set framework of [shinohara1991teachability] [goldman1995complexity].
