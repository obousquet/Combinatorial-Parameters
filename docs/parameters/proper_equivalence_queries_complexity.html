Proper Equivalence Queries Complexity

Name: Proper Equivalence Queries Complexity

Symbol:
\[\mathrm{Q}_{\mathrm{peq}}\]
Definition:

The Proper Equivalence Queries Complexity of $\mathcal{H}$ is the minimum worst-case number of equivalence queries needed to identify an unknown target in $\mathcal{H}$, when every proposed equivalence hypothesis must itself belong to $\mathcal{H}$.

Origin References:

Equivalence queries in the exact query-learning model are introduced in [angluin1988queries]; this parameter restricts the learner's equivalence hypotheses to $\mathcal{H}$.

Category: Queries
