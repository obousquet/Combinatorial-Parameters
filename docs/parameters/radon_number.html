Radon Number

Name: Radon Number

Symbol:
\[\mathrm{Rad}\]
Definition:

For a finite binary class $\mathcal H$, form the convexity space on ground set $\mathcal H$ whose convex sets are the version spaces $\{h\in\mathcal H:h|_S=y\}$ and their intersections. A set $\{h_1,\ldots,h_k\}\subseteq\mathcal H$ is Radon independent if, for every nontrivial partition $I\sqcup J=[k]$, the convex hulls of $\{h_i:i\in I\}$ and $\{h_j:j\in J\}$ are disjoint. The Radon number $\mathrm{Rad}(\mathcal H)$ is the largest size of a Radon-independent subset.

Description:

The Radon number of the convexity space naturally associated with a concept class; introduced for this setting by Chase, Chornomaz, Hanneke, Moran, and Yehudayoff.

Origin References:

Defined for concept classes in [chase2024dual].
