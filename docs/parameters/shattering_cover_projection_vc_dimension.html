Shattering-Cover Projection VC Dimension

Name: Shattering-Cover Projection VC Dimension

Symbol:
\[\mathrm{SCVC}\]
Definition:

For a finite binary class $\mathcal H$ on domain $\mathcal X$, define $\mathrm{SCVC}(\mathcal H)=\min\{\mathrm{VC}(\mathcal H_{|S}):S\subseteq\mathcal X,\ |\operatorname{sh}(\mathcal H_{|S})|\geq|\mathcal H|\}$. The minimum is well-defined because $S=\mathcal X$ is admissible by the sandwich theorem.

Description:

A candidate projection-based characterization of interpolation degree; it is retained because the proposed equality is explicitly refuted below.

Origin References:

This quantity formalizes the draft conjecture in the interpolation-degree discussion of the companion survey.
