Stable Unlabeled Complexity

Name: Stable Unlabeled Complexity

Symbol:
\[\mathrm{sUSC}\]
Definition:

For a finite realizable labeled sample $A$, an unlabeled compression scheme of size $k$ selects a set $C(A)\subseteq\operatorname{dom}(A)$ with $|C(A)|\le k$ and reconstructs a hypothesis consistent with $A$ from the labels on $C(A)$. It is stable when $C(A)\subseteq\operatorname{dom}(B)\subseteq\operatorname{dom}(A)$ implies that reconstructing from $B$ gives the same hypothesis as reconstructing from $A$. The Stable Unlabeled Complexity is the least such $k$.

Origin References:

The stability condition for sample compression schemes is used in [bousquet2020proper] [hanneke2021stable].
