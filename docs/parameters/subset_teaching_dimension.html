Subset Teaching Dimension

Name: Subset Teaching Dimension

Symbol:
\[\mathrm{STD}\]
Definition:

Let $\mathrm{STS}^{0}(h,\mathcal H)$ be the set of all ordinary minimum teaching samples for $h$. Given $k$ and a sample $S$, set $\mathrm{Cons}_{\mathrm{sub}}(S,\mathcal H,k)=\{h'\in\mathcal H:\exists S'\in\mathrm{STS}^{k}(h',\mathcal H), S\subseteq S'\}$. Then $\mathrm{STD}^{k+1}(h,\mathcal H)$ is the smallest $|S|$ for which this set is $\{h\}$, and $\mathrm{STS}^{k+1}(h,\mathcal H)$ contains all minimizers. Once these sets stabilize, the Subset Teaching Dimension is the maximum stabilized value over $h$.

Description:

An iteratively defined teaching parameter. It is at most ordinary teaching dimension, but is neither comparable with Balbach nor recursive teaching dimension nor monotone under subclasses.

Origin References:

Introduced in [zilles2011models].
