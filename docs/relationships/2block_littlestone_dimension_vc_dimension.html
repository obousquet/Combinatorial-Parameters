2-Block Littlestone Dimension / VC Dimension

Name: 2-Block Littlestone Dimension / VC Dimension

Parameter 1: 2-Block Littlestone Dimension

Parameter 2: VC Dimension

Relationship Type: $P_1\ge P_2$

Variant:

Details:

A VC-shattered set gives a level-constant 2-block tree.

Witness: Branching Batch-Tree Class

Witness Strength: Unbounded gap

Witness Verification:

Fix b=2 in the branching batch-tree class and let n grow. The exact values B_2=2n and VC=2 give B_2/(1+VC)=2n/3 tending to infinity. Thus no reverse affine bound, or even any finite-valued bound in VC alone, exists. See survey Corollary prop:branching-batch-separations and the database-owned value proofs.

Status: Established

Proof or Proof Sketch:

If $S=\{x_1,\ldots,x_d\}$ is VC-shattered, label every node on level $i$ by $x_i$. This is a shattered tree of depth $d$ and satisfies the 2-block constraint (indeed, it is level-constant everywhere). Hence $\mathrm{B}_2(\mathcal H)\ge\operatorname{VC}(\mathcal H)$.

Full Proof:

Proposition \ref{prop:block-littlestone-sandwich} in the survey.
