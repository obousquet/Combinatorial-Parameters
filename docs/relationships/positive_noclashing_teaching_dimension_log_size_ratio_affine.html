Positive No-Clashing Teaching Dimension / Log Size Ratio (affine)

Name: Positive No-Clashing Teaching Dimension / Log Size Ratio (affine)

Parameter 1: Positive No-Clashing Teaching Dimension

Parameter 2: Log Size Ratio

Relationship Type: $P_1\ge cP_2-d$

Multiplicative Constant: \tfrac12

Variant:

Details:

Every finite nontrivial binary class satisfies $\mathrm{NCTD}^{+}(\mathcal H)\geq\tfrac12\,\log(|\mathcal H|-1)/\log(n+1)$, where $n$ is the ambient domain size.

Witness: Full Cube

Witness Strength: Unbounded gap

Witness Verification:

For the family Full Cube with n>=4, the established endpoint values or bounds, in parameter order, are $n$ and $\frac{\log(2^n-1)}{\log(n+1)}$. The first parameter divided by one plus the second tends to infinity as n tends to infinity, ruling out every reverse affine-linear bound. See the database-owned value proofs for these two endpoints.

Status: Established

Proof or Proof Sketch:

Every positive no-clashing teacher is in particular a no-clashing teacher. Thus $\mathrm{NCTD}^{+}(\mathcal H)\geq\mathrm{NCTD}(\mathcal H)$, and the no-clashing counting argument gives the stated log-size-ratio lower bound directly.

Full Proof:

Corollary cor:positive-nctd-low-log-size-ratio in the LaTeX survey.
