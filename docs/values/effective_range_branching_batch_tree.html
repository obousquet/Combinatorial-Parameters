Effective Range of the Branching Batch-Tree Class

Name: Effective Range of the Branching Batch-Tree Class

Class: Branching Batch-Tree Class

Parameter: Effective Range

Value: $b(2^{bn}-1)/(2^b-1)$

Order:

Details: For construction width $b\ge1$ and height $n\ge1$. Query block size $k$ is a separate fixed integer; the general block catalogue parameter uses $k>2$. Any asymptotic statement fixes $b,k$ and lets $n$ grow.

Status: Established

Proof or Derivation:

There are $\sum_{t=0}^{n-1}2^{bt}=(2^{bn}-1)/(2^b-1)$ tree nodes, each with $b$ coordinates. Every coordinate varies: choose a word visiting its node with the corresponding next bit zero, and another with that next bit one. Thus the entire domain is effective.

References:

Direct finite tree construction, with independent checks in the branching-batch-tree regression.
