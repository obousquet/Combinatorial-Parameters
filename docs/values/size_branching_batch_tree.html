Class Size of the Branching Batch-Tree Class

Name: Class Size of the Branching Batch-Tree Class

Class: Branching Batch-Tree Class

Parameter: Size

Value: $2^{bn}$

Order:

Details: For construction width $b\ge1$ and height $n\ge1$. Query block size $k$ is a separate fixed integer; the general block catalogue parameter uses $k>2$. Any asymptotic statement fixes $b,k$ and lets $n$ grow.

Status: Established

Proof or Derivation:

There are $|A|^n=2^{bn}$ defining words. At the first position where two words differ, the corresponding concepts disagree on at least one coordinate of their common prefix node, proving injectivity.

References:

Direct finite tree construction, with independent checks in the branching-batch-tree regression.
